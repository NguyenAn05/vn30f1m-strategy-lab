# Comparing Strategies

No comparison or performance ranking has been made.

Write the comparison plan before evaluating strategies:

- Use a common evaluation period, starting capital, and risk limits. Explain any differences in usable data coverage.
- Use the same contract metadata, accounting, fees, and metric definitions. Choose fill assumptions that fit each strategy's orders and available data.
- Compare net returns, drawdown, capital and margin use, turnover, trade counts, holding periods, cost sensitivity, and behavior in different market conditions.
- Define baselines, acceptance criteria, tuning budgets, and selection rules. Keep all tested settings and manual changes.
- Use validation data for development and selection. Evaluate frozen candidates on the final holdout. Record any later use of those results to choose or change a strategy; confirm that choice with new data.
- Report open positions, incomplete executions, data exclusions, and the effects of missing observations.

Check return correlation when enough evidence is available. Different strategy names do not guarantee different sources of returns.

A combined portfolio needs its own rules for capital, net positions, and orders.
